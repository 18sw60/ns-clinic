# NS Clinic sales demo

React / Vinext website. Central business settings and structured treatment data: `lib/clinic.ts`. Set `bookingURL` when supplied; all booking buttons currently open `/contact`. The enquiry form prepares a WhatsApp message locally and requires the visitor to send it. No data submission backend or appointment reservation is implied.

15 core pages plus four demo legal pages. Private demo is marked noindex. Unverified reviews, results, hours, prices and practitioner credentials are not fabricated. Wellness injectables, teeth whitening and specific laser availability require final confirmation. The whole treatment catalogue needs clinic approval before public launch. Canonicals use the registered demo origin; update them for a production domain.
